# CCcat 海龟汤 🐢 — 完整游戏说明文档

> 基于原 CCcat 猜词大挑战改造的抖音直播弹幕海龟汤互动游戏
> 双轨道并行：逐字解密（Track A）+ 是非问答（Track B）

---

## 一、游戏简介

海龟汤（Situation Puzzle）是一种情境猜谜游戏。主持人给出一个简短的故事开头（汤面），玩家通过提问来还原完整的故事（汤底）。主持人只能回答"是"、"不是"或"是也不是"。

本项目将这一游戏形式与 **抖音直播弹幕** 结合，观众通过发送弹幕参与猜谜，AI 自动判断弹幕的准确性，同时提供逐字解密的辅助轨道。

### 核心玩法

- **Track A — 逐字解密**：观众发送的弹幕中的每个字符自动与汤底匹配，命中则揭示全文所有相同字符。这是"歪打正着"的趣味通道。
- **Track B — 是非问答**：弹幕经过 AI（Qwen2.5 / LLM API）三分类，判断为"是"、"不是"还是"是也不是"，并以气泡形式展示在直播间。

### 特色功能

- 🎯 **双轨道并行**：逐字揭示 + 是非问答同时进行
- 🤖 **AI 智能分类**：LLM 实时分析弹幕与汤底的相关性
- 🎁 **礼物互动**：6种礼物触发不同游戏效果
- 🔊 **TTS 语音播报**：自动朗读弹幕结果和游戏提示
- 🛡️ **防卡死机制**：长时间无进展时自动揭示关键字符
- 📊 **贡献排行榜**：观众揭示字数排行

## 三、弹幕处理管道详解

### 处理流程

```
弹幕进入
    │
    ▼
┌─────────────────────┐
│ Layer 1: 规则过滤    │ ← 毫秒级，拦截"不相关"
│ 纯标点/纯数字/     │   "哈哈哈""666""主播好"→丢弃
│ 纯表情/长度检查     │   长度 < 2 或 > 50
└──────────┬──────────┘
           │ 通过
           ▼
┌─────────────────────┐
│ 轨道A: 逐字解密     │ ← 每条弹幕必走，永远不拦截
│ 检查每个字是否属于  │   命中 → 全文同字揭示
│ "待揭示实词集合"    │   不命中 → 不揭示
└──────────┬──────────┘
           │ 继续传递
           ▼
┌─────────────────────┐
│ 第二层过滤            │ ← 弹幕内容过滤
│ 关键词黑名单/      │   "哈哈哈/666/签到"→"不相关"
│ 长度 < 3 或 > 30   │
└──────────┬──────────┘
           │ 通过
           ▼
┌─────────────────────┐
│ 轨道B: Qwen 三分类   │ ← LLM API / 本地模型
│ 输入：汤底原文+弹幕  │   输出：是/是也不是/不是
│ 结果→问答气泡展示    │
└─────────────────────┘

四种结果气泡展示：
  🟢 是         — 绿色标签
  🟡 是也不是    — 黄色标签
  🔴 不是        — 红色标签
  ⚪ 不相关      — 灰色标签
```

### 规则过滤（Layer 1）

```python
IRRELEVANT_PATTERNS = [
    # 纯 emoji
    re.compile(r'^[\U0001F600-\U0001F6FF]+$'),
    # 666/哈哈哈
    re.compile(r'^(6{2,}|666+|哈哈哈+|呵呵+)+$'),
    # 常见无意义弹幕
    re.compile(r'^(主播|老师|大佬|好厉害|加油|来了|签到)+'),
    # 长度过短
    re.compile(r'^.{0,2}$'),
]
```

## 四、轨道A：逐字解密

### 打码规则

| 类型 | 处理 | 示例 |
|------|------|------|
| 实词 | 参与解密，初始打码 | "男、人、走、进、酒、吧、要、水..." |
| 虚词 | 开局直接揭示 | "的、了、是、在、和、吗" |
| 标点 | 开局直接揭示 | "，。、？！；：""''" |

### 揭示逻辑

```javascript
function processTrackA(danmaku, soup) {
  for (const char of danmaku) {
    if (soup.unrevealedChars.has(char)) {
      soup.revealChar(char);  // 全文同字同时揭示
    }
  }
  const progress = soup.revealedCount / soup.totalRealChars;
  if (soup.isAllRevealed()) {
    triggerWin();
  }
}
```

### 揭示进度计算

```
progress = (已揭示实词数 / 总实词数) × 100%

示例：汤底共 120 个字符，其中 80 个实词、40 个虚词/标点
      已揭示 40 个实词 → 进度 50%
```

## 五、轨道B：是非问答

### 题库结构

```typescript
interface SoupData {
  id: string;           // 唯一标识
  title: string;        // 题目名称
  surface: string;      // 汤面（故事开头）
  bottom: string;       // 汤底（完整答案）
  keywords: string[];   // 关键词列表（辅助分类）
  difficulty: 'easy' | 'medium' | 'hard';
  specificQuestions: Array<{
    text: string;       // 问题
    answer: '是' | '不是' | '是也不是';
  }>;
}
```

### LLM 分类系统 Prompt

```text
你是一个海龟汤游戏的答案判断器。
根据汤底和关键词，判断玩家弹幕与答案的相关性。
只回复以下三个选项之一：
- 是：弹幕内容非常接近正确答案或包含核心关键词
- 不是：弹幕内容与正确答案完全无关
- 是也不是：弹幕部分正确但不完整，或者方向对但细节不对
```

## 六、礼物系统

### 礼物效果一览

| 礼物 | 效果 | 说明 |
|------|------|------|
| 🎈 人气票 | 方向引导提示 | 每次送触发 |
| 🍺 啤酒 | 揭示一个实词字 | 全文同字揭示 |
| 🍭 棒棒糖 | 揭示一整句话 | 到逗号为止 |
| 🕶️ 墨镜 | 揭示全文通关 | 直接看答案 |
| ⭐ 粉丝灯牌 | 揭示一句话 | 每局最多3次 |
| 👍 点赞 | 每500赞揭示一字 | 持续累积 |

### 礼物索要话术

在以下时机自动生成礼物索要话术（由 LLM 动态生成）：
- 连续 3 条弹幕未命中实词
- 点赞进度条停滞
- 观众连续猜错方向
- 随机间隔（每 3-5 分钟）

## 七、防卡死机制

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 时间阈值 | 3 分钟 | 无新字揭示时触发 |
| 弹幕阈值 | 50 条 | 连续无命中时触发 |
| 衰减系数 | 0.8 | 每次触发缩短 20% |
| 触发效果 | 揭示 1 个高频实词 | 优先选高频字 |

触发逻辑：**或逻辑**，任一条件满足即触发，不等两个条件都满足。

```
第一次触发：3min / 50条
第二次触发：2.4min / 40条
第三次触发：1.9min / 32条
...
```

## 八、语音系统（TTS）

### 播报规则

| 规则 | 说明 |
|------|------|
| 弹幕结果播报 | 只念弹幕 + 停顿 + 结果，不加人名 |
| 礼物播报 | 打断当前播报，先感谢礼物 |
| 点赞 | 弹幕多时不播报 |
| 通关播报 | 恭喜揭开谜题 → 朗读全文，不可打断 |
| 弹幕堆积 | 后进先出队列，优先播最新弹幕 |

### 各阶段播报

```
开局 → 汤面全文朗读（可打断）
弹幕阶段 → 弹幕原文 + 停顿 + 结果
        → 礼物打断当前，先感谢
通关 → 恭喜 → 朗读全文（不可打断）
    → 清缓存 → 5秒后下一局
```

## 十、快速开始

### 环境要求

- **OS**: Windows 10/11
- **Python**: 3.11+
- **Node.js**: 18+
- **RAM**: 2GB+（使用 LLM API 无需本地模型）
- **LLM API Key**: 支持 OpenAI / DeepSeek / 任意兼容 API

### 一键启动

```bash
# 1. 配置 API Key
编辑 .env 文件，填入你的 LLM_API_KEY

# 2. 一键启动所有服务
start_all.bat
```

### 手动启动

```bash
# 1. 后端
cd backend
pip install -r requirements.txt
python qwen_server.py   # LLM 分类服务（端口 3009）
python game_server.py   # 游戏引擎（端口 3010）

# 2. 前端
cd meoo_frontend
npm install
npm run dev              # 开发服务器（端口 3015）
```

### 访问

- 游戏界面: http://localhost:3015
- LLM 服务健康检查: http://localhost:3009/health
- 游戏 WS: ws://localhost:3010
