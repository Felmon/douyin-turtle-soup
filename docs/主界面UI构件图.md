## 二、UI 板块拆解

### 板块 1：品牌栏（顶部）

```
┌──────────────────────────────────────────────────────────────────────┐
│  🐱 CCcat 海龟汤                           [🎤测试语音] [🎚控制台]  │
└──────────────────────────────────────────────────────────────────────┘
```

| 元素 | 说明 |
|------|------|
| 🐱 | Logo |
| CCcat 海龟汤 | 渐变标题 |
| [🎤测试语音] | 语音测试/开关按钮 |
| [🎚控制台] | 主播控制面板入口（仲裁面板 + 参数调节） |

---

### 板块 2：汤面播报区

```
┌──────────────────────────────────────────────────────────────────────┐
│  📖 汤面                                                        [▶重播] │
│  "一个男人走进酒吧，向酒保要了一杯水。酒保却拿出一把枪指着他..."    │
│  ▁▂▃▄▅▆▇█  TTS 播报中...                                              │
└──────────────────────────────────────────────────────────────────────┘
```

| 状态 | 显示 |
|------|------|
| 开局 | 汤面全文 + TTS 波形动画 + 可点击"跳过" |

| 有 | 可点击收缩/展开 |

---

### 板块 3：逐字揭示区（核心视觉焦点、占比最大）

```
┌──────────────────────────────────────────────────────────────────────┐
│  店员每天晚上要丢弃卖不出去的 ▓▓▓▓，巷子里有一只 ▓▓▓               │
│  每天晚上准时来 ▓▓▓门口等。▓▓怕 ▓▓▓▓，又怕被店员误会，            │
│  于是每天提前 ▓▓，想在 ▓▓被扔进 ▓▓▓前 ▓▓喂猫。                     │
│                                                                      │
│  图例:  虚词（灰色）  ▓实词打码（白色框）  猫已揭示（粉色高亮）    │
└──────────────────────────────────────────────────────────────────────┘
```

**字号规范：** 全文展示，每行约 18-22 个字，字间距 2px

| 字符状态 | 样式 | 色值 |
|---------|------|------|
| 虚词/标点 | 灰色细体 | #666699 |
| 实词（未揭示）| 白色半透明底 + ▓ 占位 | rgba(255,255,255,0.15) |
| 实词（已揭示）| 粉色高亮 | #ff6b9d |
| 刚揭示动画 | 闪烁放大 1.2x → 恢复 | 过渡 0.5s |

**揭示动画：** 当弹幕命中某个字时，该字位置闪烁放大 → 变为高亮色，持续 0.5s。

### 板块 4：进度条区

```
┌──────────────────────────────────────────────────────────────────────┐
│  揭示  ████████████████████████░░░░░  65%     实词 52/80   ▓ 已揭示 40 │
│  点赞  ████████████████░░░░░░░░░░░░░  342/500  💖 揭示一个字的进度  │
```

| 进度条 | 颜色 | 触发器 |
|--------|------|--------|
| 揭示进度 | 粉色渐变 #ff6b9d → #ffa726 | 命中实词时更新 |
| 点赞进度 | 蓝色渐变 #6bcbff → #4ade80 | 每500赞揭示一字 |
| 防卡死 | (无进度条) | 超时/超弹幕时触发 |

### 板块 5：问答气泡流（轨道B + 弹幕流 合并区域）

```
┌────────────────────────────────┐
│ 💬 问答气泡                    │
│                                │
│ ┌─────────────────────────┐   │
│ │ 🧑 流浪猫                │   │
│ │ 和钱有关吗？             │   │
│ │ 🟢 是                    │   │
│ └─────────────────────────┘   │
│                                │
│ ┌─────────────────────────┐   │
│ │ 🧑 小鱼干                │   │
│ │ 有人死了吗？             │   │
│ │ 🔴 不是                   │   │
│ └─────────────────────────┘   │
│                                │
│ ┌─────────────────────────┐   │
│ │ 🧑 大鱼                  │   │
│ │ 凶手是男的吗？           │   │
│ │ 🟡 是也不是              │   │
│ └─────────────────────────┘   │
│                                │
│ ┌─────────────────────────┐   │
│ │ 🧑 喵喵                  │   │
│ │ 哈哈哈（不相关）         │   │
│ │ ⚪ 不相关                 │   │
│ └─────────────────────────┘   │
└────────────────────────────────┘
```

**气泡颜色：** 不同答案对应不同颜色标签

```
🟢 是         →  绿色标签  #4ade80
🔴 不是        →  红色标签  #ff4444
🟡 是也不是    →  黄色标签  #ffd700
⚪ 不相关      →  灰色标签  #666699
💬 系统提示    →  紫色标签（礼物索要/防卡死提示）
```

**数据结构：**

```javascript
{
  user: "流浪猫",
  text: "和钱有关吗？",
  answer: "是",         // 是 / 不是 / 是也不是 / 无关
  source: "trackB",      // trackB / 系统提示
  timestamp: 1234567890,
}
```

## 三、组件层级树

```
App.jsx
├── BrandBar                  # 品牌栏
├── StoryBanner               # 汤面播报区  [新增]
│   └── TTSWaveIndicator      # TTS波形指示
├── CharacterReveal           # 逐字揭示区  [新增，替代原PinyinDisplay]
│   ├── RevealRow             # 逐行展示
│   └── RevealAnimation       # 揭示动画
├── ProgressBar               # 进度条区    [新增]
│   ├── RevealProgress        # 揭示进度条
│   └── LikeProgress          # 点赞进度条
├── MainSplit                 # 主分割区
│   ├── QaBubblePanel         # 问答气泡流  [新增]
│   │   └── QaBubble          # 单条气泡
│   ├── GiftPanel             # 礼物面板（原）
│   │   ├── GiftButtons       # 礼物按钮
│   │   ├── FanBadge          # 粉丝灯牌
│   │   └── GiftNotice        # 礼物通知（原）
│   ├── ChatPanel             # 弹幕流（原，可选）
│   └── Leaderboard           # 排行榜（原，统计方式改为揭示字数）
├── BottomBar                 # 底部状态栏（原，修改字段）
└── WinnerModal               # 通关弹窗（原，修改内容）
```

## 四、与猜词 UI 的差异总结

| 原猜词组件 | 新海龟汤组件 | 变化说明 |
|-----------|-------------|---------|
| PinyinDisplay | CharacterReveal | 从单行拼音揭示改为全文逐字揭示 |
| 相似度进度条 simi-bar | RevealProgress | 从 BGE 相似度改为实词揭示进度 |
| — | LikeProgress | 新增点赞累积进度条 |
| ChatPanel（纯弹幕流） | QaBubblePanel + ChatPanel | 新增问答气泡展示层 |
| — | StoryBanner | 新增汤面播报区 |
| — | AntiStallIndicator | 新增防卡死状态（可选） |
| Leaderboard（命中次数） | Leaderboard（揭示字数） | 统计口径改为揭示字数 |
| GiftPanel（原猜词礼物） | GiftPanel（海龟汤礼物） | 礼物效果重新设计 |
| WinnerModal（恭喜猜中） | WinnerModal（恭喜揭晓） | 展示内容改为汤底全文 |
