# CCcat 海龟汤 — 优化规划方案 v2.0

> 目标：提升用户付费率 + 优化游戏逻辑
> 基于 v5.0 架构（单进程合并版）

---

## 一、现状分析

### 当前付费体系
| 维度 | 现状 | 问题 |
|------|------|------|
| 礼物 | 全部免费模拟 | ❌ 没有任何付费转化 |
| 金币 | 无虚拟货币系统 | ❌ 用户无法感知"价值" |
| 效果反馈 | 简单TTS播报 | ❌ 缺乏视觉冲击 |
| 稀缺感 | 礼物无限发送 | ❌ 无消费动力 |
| 排行榜 | 基础的揭示贡献榜 | ❌ 不关联消费 |
| 留存机制 | 无 | ❌ 没有每日/签到 |
| VIP | 无 | ❌ 没有付费身份认同 |

### 当前游戏逻辑
| 维度 | 现状 | 问题 |
|------|------|------|
| 难度 | 随机选题 | ❌ 无难度递进 |
| 防卡死 | 180s/50条弹幕触发 | ⚠️ 阈值太保守 |
| 连击 | 无 | ❌ 无操作激励 |
| 揭示范式 | 同字全显 | ✅ OK |
| LLM分类 | 基础prompt | ⚠️ 可优化 |

## 二、付费率提升方案（重点）

### 2.1 虚拟货币系统 ⭐
**目的**：让礼物有"价格"，用户感知价值

```
金币（虚拟货币）
  ├── 新用户赠送 100 金币
  ├── 每日签到 +30 金币
  ├── 限时活动赠送
  └── 充值入口（模拟/真实支付）
```

**礼物定价表**：
| 礼物 | 价格(金币) | 效果 |
|------|-----------|------|
| 点赞 | 免费 | 累积500赞揭示1字 |
| 粉丝灯牌 | 20 | 揭示未完全揭示的从句 |
| 人气票 | 30 | LLM生成方向提示 |
| 啤酒 | 50 | 揭示1个高频实词 |
| 棒棒糖 | 80 | 揭示一整句 |
| 墨镜 | 200 | 直接通关 |

**实现**：后端增加 `CoinSystem` 类（已完成），前端增加金币展示和商店面板

### 2.2 礼物连击系统 ⭐
**目的**：鼓励连续消费，倍率递增制造紧迫感

```
连击规则：
  30秒内连续送礼物 → 叠加连击数
  
  连击数  倍率  奖励
  1-2     1.0x  基础效果
  3-4     1.5x  额外揭示+1字
  5-9     2.0x  额外揭示+2字
  10+     3.0x  额外揭示+3字 + 全屏特效
  
  超过30秒未送 → 连击重置
```

**视觉反馈**：连击数在屏幕顶部动态显示，连击时闪烁+震动

### 2.3 每日签到 ⭐
**目的**：提高日活，养成打开习惯

```
每日签到 → 领取30金币
  ├── 连续3天签到 → 额外+20金币
  ├── 连续7天签到 → 额外+50金币 + 免费棒棒糖
  └── VIP双倍领取
```

**实现**：后端记录 `daily_claimed`（已完成），前端展示签到面板

### 2.4 VIP会员系统
**目的**：提供订阅式付费身份

```
VIP月卡  → 198金币（或真实货币）
  特权：
  ├── 每日签到双倍金币
  ├── 礼物连击不掉落（60秒重置）
  ├── 专属VIP标识（头像框）
  ├── 每局免费1次棒棒糖
  └── 参与VIP专属谜题
```

### 2.5 消费排行榜
**目的**：社交攀比驱动消费

```
排行榜（当前游戏内/累计）
  ├── 本局贡献榜 ✅（已实现）
  ├── 历史消费榜（金币总消费）
  └── 弹幕活跃榜（猜对最多）
```

### 2.6 限时礼物效果
**目的**：制造稀缺感和紧迫感

```
开局后：
  - 前30秒礼物效果翻倍（双倍揭示）
  - 进度<30%时啤酒效果+1字
  - 进度>80%时棒棒糖价格8折
  - 通关后打赏感谢榜
```

## 三、游戏逻辑优化方案

### 3.1 难度递进系统 ⭐
**目的**：玩家体验从易到难，增加策略性

```
难度选择（开局前）：
  ├── 简单（5题）：直接匹配词，虚词占比高，汤底较短
  ├── 中等（6题）：标准匹配，标准虚词比例
  └── 困难（4题）：复杂故事，实词占比高

谜题分类（基于data_soups.py现有题库）：
  简单：soup-002(电梯), 004(酒吧), 006(父子), 007(关灯), 009(帽子)
  中等：soup-001(海龟汤), 003(沙漠), 010(雪夜), 011(红绿灯), 012(画家)
  困难：soup-005(双胞胎), 008(戒烟), 013(电梯惊魂), 014(遗书), 015(误入)
```

### 3.2 防卡死机制优化
**目的**：更智能的防止游戏停滞

```
当前阈值：
  时间：180秒 → 优化：逐步缩短（梯度衰减）
  弹幕：50条  → 优化：观察弹幕活跃度动态调整

优化后：
  Phase 1（前2分钟）：180秒 / 50条
  Phase 2（2-5分钟）：120秒 / 30条
  Phase 3（5分钟+）：60秒 / 15条
  
  揭示频率高的礼物（啤酒等）会重置衰减
```

### 3.3 进度里程碑
**目的**：在每个关键节点给用户正反馈

```
里程碑触发点：
  25% → "进展不错！看看提示？" + 推荐人气票
  50% → "完成一半了！" + 棒棒糖限时8折
  75% → "马上就要揭晓了！" + 推荐墨镜快速通关
  90% → "还差最后几个字！" + 限时特惠包
```

### 3.4 LLM提示优化
**目的**：更准确的弹幕分类和更有用的提示

```
弹幕分类prompt增强：
  - 加入汤面上下文（不仅是汤底）
  - 加入前3条问答历史
  - 提供关键词权重提示

方向提示prompt增强：
  - 明确指出已猜对的方向
  - 提醒尚未触及的关键线索
  - 用角色视角提示（如果是XX会怎么想）
```

### 3.5 前端交互优化
**目的**：更流畅、更有趣的交互体验

```
嵌入式HTML改进：
  ├── 主界面：金币展示 + 礼物商店入口
  ├── 游戏中：连击指示器 + 进度里程碑提示
  ├── 礼物面板：显示价格 + 余额 + 购买确认
  ├── 通关面板：消费榜 + 邀请继续游戏
  ├── 签到面板：每日签到按钮 + 连签奖励
  ├── 充值面板：各档位选择 + VIP介绍
  └── 难度选择：开局前可选

React前端跟进同步优化
```

## 四、付费转化漏斗设计

```
发现 → 试用 → 留存 → 付费 → 复购
 │       │       │       │      │
 │   免费100金  每日签到  连击效果  VIP月卡
 │   首次送礼  进度推送  限时折扣  活动充值
 │             排行榜    断签提醒
```

### 具体转化节点

| 阶段 | 触发时机 | 转化动作 |
|------|---------|---------|
| 发现 | 用户打开游戏 | 展示金币余额+商店入口 |
| 试用 | 第1次送免费礼物 | 展示礼物效果动画 |
| 试用 | 防卡死揭示后 | "送啤酒可快速揭示" |
| 留存 | 每日首次打开 | 签到领取金币弹窗 |
| 付费 | 游戏进度30% | "进度有点慢，送个人气票？" |
| 付费 | 连击3次后 | "连击送不停！再来一个翻倍！" |
| 付费 | 进度80% | "最后冲刺！墨镜直接通关！" |
| 复购 | 金币<20 | 金币不足弹窗 → 充值面板 |
| 复购 | 签到断签 | 补签卡（付费） |

## 七、风险与注意事项

| 风险 | 影响 | 缓解 |
|------|------|------|
| 虚拟货币系统复杂度 | 开发成本 | 先做最小可行版本 |
| 连击可能被滥用 | 游戏平衡 | 30秒超时重置 |
| 充值对接真实支付 | 合规/安全 | 先模拟，延后真实 |
| 前端改动量大 | 时间成本 | 优先修改嵌入式HTML |
| 每日签到存储 | 持久化 | 先用内存(dict)，后续SQLite |
